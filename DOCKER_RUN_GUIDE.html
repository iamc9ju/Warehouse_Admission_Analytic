📋 ความต้องการของระบบ (Prerequisites)

• ติดตั้งโปรแกรม Docker Desktop (Windows / macOS) หรือ Docker Engine (Linux)
• พอร์ต 3000 (เว็บแอปพลิเคชัน) และ 5432 (ฐานข้อมูล PostgreSQL) ต้องไม่มีโปรแกรมอื่นใช้งานค้างอยู่

🚀 ขั้นตอนการติดตั้งและรันระบบแยกตาม Service (Production Docker)

1 Clone Repository และตั้งค่าไฟล์ .env
เปิด Terminal แล้วรันคำสั่งเพื่อดึงโปรเจกต์และกำหนดค่า Runtime Environment Variables:
git clone https://github.com/iamc9ju/Warehouse_Admission_Analytic.git
cd Warehouse_Admission_Analytic
git checkout devdev2   # หรือ main (โค้ดตรงกัน 100%)
cp .env.example .env   # กำหนดค่า DATABASE_URL และ GEMINI_API_KEY ในไฟล์ .env
2 สร้าง Network, Volume และรันบริการฐานข้อมูล PostgreSQL + โหลดข้อมูล
สร้าง Docker Network/Volume รัน PostgreSQL Container และนำเข้า Schema/ข้อมูล (หรือใช้ DATABASE_URL ของ Neon):
docker network create admissions-net
docker volume create admissions_pgdata

docker run -d --name admissions-db --network admissions-net --restart unless-stopped \
  -e POSTGRES_USER=postgres -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=admissions_dw \
  -p 5432:5432 -v admissions_pgdata:/var/lib/postgresql/data postgres:16-alpine

# โหลด Schema (หรือใช้ docker/init.sql หากต้องการโหลดข้อมูลตั้งต้น 13,799 แถว):
docker exec -i admissions-db psql -U postgres -d admissions_dw < docker/init.sql
3 Build Production Image (Multi-Stage) และรัน Web Application Service
สร้าง Image จาก Dockerfile (Standalone Output) รัน Migration และเริ่มการทำงานของ Web Container:
docker build -t admission-eng:prod -f Dockerfile .

# รัน Additive Migration สำหรับตาราง AI Analysis Reports:
docker run --rm --network admissions-net --env-file .env admission-eng:prod node scripts/migrate-ai-reports.mjs

# รัน Web Application Container:
docker run -d --name admissions-web --network admissions-net --restart unless-stopped \
  -p 3000:3000 --env-file .env admission-eng:prod
4 เปิดใช้งานผ่าน Web Browser
เมื่อ Container สตาร์ทเรียบร้อย สามารถเปิดเบราว์เซอร์ไปที่:
บริการ URL / Connection คำอธิบาย
Web Dashboard http://localhost:3000 หน้าแดชบอร์ดสถิติผู้สมัคร, ยืนยันสิทธิ์, และแนวโน้ม TCAS
AI Analysis http://localhost:3000/ai-analysis ระบบวิเคราะห์ข้อมูลเชิงลึกด้วย AI (Google Gemini 3.1)
PostgreSQL Database localhost:5432 Database: admissions_dw | User: postgres | Pass: postgres
5 การตรวจสอบ Log และการหยุด/ลบ Container 
# ดู Log การทำงานของ Web Service แบบ Real-time
docker logs -f admissions-web

# หยุดและลบ Container เมื่อเลิกใช้งาน
docker stop admissions-web admissions-db
docker rm admissions-web admissions-db

🏛️ โครงสร้างฐานข้อมูล Data Warehouse (Star Schema)

ฐานข้อมูลจะถูก Initialize อัตโนมัติจากไฟล์ docker/init.sql ประกอบด้วย:
ประเภทตาราง ชื่อตาราง / วัตถุ รายละเอียดข้อมูล
Fact Table fact_admission บันทึกข้อมูลธุรกรรมการสมัคร 13,799 รายการ (เชื่อมโยงคะแนนและผลการคัดเลือก)
Dimension Tables dim_student, dim_major, dim_year, dim_faculty, dim_tcas_round, dim_tcas_status มิติข้อมูลนักเรียน (10,158 คน), 10 สาขาวิชา, รอบ TCAS 1-4, ปีการศึกษา 2567-2569
Analytical Marts 16 Views (เช่น mart_admissions_round_overview) คำนวณอัตรายืนยันสิทธิ์, ส่วนแบ่งสาขาวิชา, และสถิติสำหรับแดชบอร์ด
AI Intelligence ai_analysis_reports, ai_analysis_jobs ประวัติการสรุปและวิเคราะห์รายงานด้วย Google Gemini 3.1 Flash-Lite
